A comprehensive AI/ML developer tool for lifelong personalized tutoring and learning.

## Overview

DeepTutor provides:
- Intelligent tutoring systems
- Personalized learning paths
- Knowledge base management
- Interactive chat and reading surfaces
- Mastery path tracking
- Real-time feedback and assessment

## Getting Started

### Installation

```bash
# Clone this repository
git clone <repository-url>
cd atlas-observatory-145

# Install dependencies
pip install -r requirements.txt

# Set up environment
cp .env.example .env

# Start the application
python -m deep_tutor start
```

### Basic Usage

```bash
# Start the DeepTutor service
deeptutor start --home ./data

# Run web interface
curl -s http://localhost:8001
```

## Key Features

- **Learning Surfaces**: Chat, Reading, Question answering, and Mastery Paths
- **Knowledge Base**: Document ingestion, vector search, and RAG capabilities
- **Multi-user Support**: Learner, Admin, and Guardian accounts
- **Modular Architecture**: Pluggable modules for extensibility
